# Dawson Burchell — Portfolio Website

A personal portfolio website for **Dawson Z. Burchell, CCA** (Continuing Care Assistant), showcasing his professional background, certifications, journey, and care philosophy.

---

## Overview

This is a static multi-page HTML/CSS/JavaScript portfolio built to present Dawson's qualifications, experience, and passion for empathetic elderly care. The site is designed with a warm, professional aesthetic and includes smooth scroll animations, parallax effects, a certification carousel, and an interactive resume.

---

## Features

- **Parallax hero sections** — Depth effect on scroll using CSS custom properties set by JavaScript
- **Fade-in animations** — Sections animate into view as the user scrolls
- **Flip-card certification carousel** — Cards flip on hover to reveal credential details; auto-scrolls every 3 seconds
- **Interactive skill bubbles** — Hover tooltips on the resume page reveal detailed role descriptions
- **Wave background** — Decorative animated wave pattern on key sections
- **Sticky navigation** — Navigation bar stays fixed at the top across all pages
- **Demo contact form** — Validates required fields and confirms submission with an alert

## Getting Started

This is a fully static website — no build tools or dependencies required.

1. Clone or download the repository.
2. Open `DawsonBurchellPortfolio/index.html` in any modern web browser.
3. Navigate between pages using the top navigation bar.

> The root `index.html` is a minimal placeholder. The main portfolio lives inside the `DawsonBurchellPortfolio/` folder.
